# SENTINEL Knowledge Layer

`Knowledge/` is the canonical validated project memory.

## Structure

- `Product/` — vision, MVP, product loop, demo contract.
- `UX/` — design system direction and information architecture.
- `Technical/` — architecture, domain model, scan pipeline, environmental memory.
- `Research/` — validated external/competitive/model research.
- `Business/` — audience, impact and future commercialization knowledge.
- `Decisions/` — explicit architecture/product decision records.

## Authority

When documents disagree, use this order:

1. Latest explicit record in `Knowledge/Decisions/`.
2. Relevant canonical `Knowledge/` specification.
3. `PROJECT_STATE.md` for execution status.
4. Existing `docs/` and `Raw/` as reference/history.

Use the AED protocol: `Capture → Organize → Validate → Apply → Test → Learn → Update → Reuse`.
