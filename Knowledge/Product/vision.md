# Product Vision

## Product

**SENTINEL — AI memory for the physical world.**

SENTINEL turns repeated observations of a physical space into a persistent, queryable environmental memory. It does not stop at describing a frame. It remembers state over time, reasons over current and historical evidence, recommends action, and verifies what changed after the environment is observed again.

## Problem

Physical environments lack the persistent operational memory software already provides for documents, databases, websites and APIs. Knowledge about a room or facility is fragmented across human memory, photos, messages, spreadsheets, inspection notes and maintenance systems.

The operational question is not merely **“What is in this image?”** It is:

- What exists here?
- What needs attention?
- Where is it?
- What changed?
- What matters most?
- What should happen next?
- Did the action actually resolve the condition?

## Product thesis

> **Every physical space can have a memory.**

SENTINEL creates that memory from ordinary observations such as phone walkthroughs, then keeps it useful across time.

## Core differentiation

Computer vision can answer what is visible now. Inspection software can classify defects. Digital twins can represent spaces. Maintenance systems can track jobs.

SENTINEL's differentiation is the **closed loop**:

`Observe → Remember → Reason → Act → Observe again → Compare → Verify → Update memory`

The signature mental model is **Git diff for reality**.

## Hackathon wedge

Primary user: **facility / operations manager**.

Reference environment: **one office**.

The hackathon proof is intentionally narrow: one controlled environment, multiple scans, grounded memory, natural-language questions, meaningful change detection, and verification.

## Long-term direction

The same memory primitive can later extend to property management, factories, schools, clinics, hotels, retail, construction and homes. Those markets are future expansion, not MVP scope.
