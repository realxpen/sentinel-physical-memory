# Hackathon Demo Flow

Target: under 3 minutes. The product should be functioning immediately; no long intro.

## Demo setup

Controlled office with three simple, visually obvious, safe changes.

Suggested Scan A baseline:

- exit path clear
- fire extinguisher at position A
- one safe staged visible condition that can later be removed

Scan B changes:

- add boxes/obstruction near the exit
- move the extinguisher
- remove the staged prior condition

Scan C:

- clear the exit obstruction for verification

## Sequence

**0:00 — Give this place a memory.**
Open on the SENTINEL product. Begin observation.

**0:10 — Observe.**
Show a short walkthrough / selected evidence extraction.

**0:25 — This space is now remembered.**
Show structured memory/evidence, not raw model JSON.

**0:40 — Ask this environment.**
Ask: “What needs my attention?” Show an evidence-backed conclusion.

**0:55 — Change the physical environment.**
Briefly show the three safe intentional changes.

**1:10 — Observe again.**
Process Scan B.

**1:30 — What changed.**
Reveal Reality Diff:

- added obstruction
- moved extinguisher
- resolved prior condition

**1:50 — Which change matters most?**
SENTINEL prioritizes the exit obstruction using current/past evidence.

**2:05 — What should I do?**
Show the concise action plan.

**2:20 — Fix + rescan.**
Clear obstruction, Scan C.

**2:45 — Verified.**
Show the route clear again, grounded in the newest evidence.

**2:55 — End.**
“The physical world now has a memory.”

## Demo rule

Never rely on fabricated production detections. If a deterministic preview fixture is shown, label it unmistakably. The submitted working path must include a real Nebius/NVIDIA runtime call.
