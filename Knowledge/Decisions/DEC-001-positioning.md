# DEC-001 — Position SENTINEL as Physical-World Memory

Date: 2026-09-06
Status: Accepted

## Decision

SENTINEL will be positioned as **persistent environmental memory + reasoning + change verification for physical spaces**, not as a generic AI building-inspection product.

Primary line:

> **SENTINEL gives physical spaces a persistent AI memory — allowing them to be scanned, understood, queried, acted upon, and verified over time.**

Demo takeaway:

> **SENTINEL does not just see a room; it remembers the room and knows when it changes.**

## Why

Object/defect detection, digital twins and inspection tools already solve parts of the problem. The differentiated product is the stateful loop across time: observe, remember, reason, act, observe again, compare and verify.

## Consequences

- Change/history/verification are core product surfaces.
- Environmental state must be durable and historical.
- The UI should emphasize memory and Reality Diff rather than generic issue dashboards.
- Future vertical workflows may build on the memory primitive, but they are not the core hackathon identity.
