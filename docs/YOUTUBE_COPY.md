## Description

SENTINEL gives physical environments persistent AI memory.

Observe a space once and SENTINEL creates a grounded environmental state. Observe it again and Reality Diff shows what changed. Ask the Building reasons over remembered evidence, Action Planner recommends next steps, and Verification checks whether the physical condition actually changed.

Core loop:

OBSERVE → REMEMBER → ASK → ACT → RESCAN → VERIFY

Built for the Nebius × NVIDIA Global AI Hackathon 2026 — Best Apps and Agents track.

Technology:
- Nebius Token Factory
- NVIDIA Nemotron 3 Nano 30B-A3B
- MiniCPM-V
- Neon Postgres
- React + TypeScript + Vite
- Vercel

Live demo:
https://sentinel-physical-memory.vercel.app

Source:
https://github.com/realxpen/sentinel-physical-memory

SENTINEL is evidence-first. It distinguishes observed evidence, model interpretation, recommended action and verified physical outcome.

Not re-observed is not resolved.
