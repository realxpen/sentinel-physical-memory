# Raw

This directory is the capture layer for unprocessed project material: hackathon notes, source exports, screenshots/moodboards, rough research, transcripts, model notes, and incoming references.

Rules:

- Preserve source meaning; do not silently rewrite raw material.
- Raw material is not automatically a product decision.
- Promote validated knowledge into `Knowledge/`.
- Once raw material is no longer active but should be retained, move it to `Archive/` with context.
